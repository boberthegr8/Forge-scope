# Forge Scope

Estimator intake, quote-readiness and AI-assisted scope capture for barns, sheds and decks.

## V1
- Manual and AI-assisted entry modes
- Field + reviewed checkbox workflow
- Barn, shed and deck templates
- Source/status tracking
- Repeatable openings and special conditions
- Saved scopes in browser storage
- Condensed scope summary with blank values removed
- JSON import/export
- Downloadable universal AI extraction prompt
- Print/PDF-ready summary

Built to match the Forge application family.
